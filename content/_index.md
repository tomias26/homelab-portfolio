## Overview

Welcome to my personal homelab documentation. This platform serves as a hands-on environment to test, validate, and deploy enterprise systems, networking strategies, containerized microservices, and smart home automation.

### Core Stack Highlights
* **Hypervisor & Server OS:** Bare-metal Linux & Unraid storage arrays
* **Containerization:** Docker & Docker Compose stacks
* **Network & Security:** Multi-VLAN segmentation, isolated NVR surveillance subnet, reverse proxy with TLS automation, and Zero-Trust remote access
* **Automation:** Home Assistant integrations, system monitoring, and multi-tier backup pipelines
